# ZenScrap Google Search Ads Copy

## Product Summary

**ZenScrap** is an AI-powered web scraping platform where users describe what they want to extract in plain language through a chat interface. The AI builds, tests, and maintains scrapers automatically — no code or CSS selectors needed. Scrapers self-heal when target sites change. Users get ready-to-use API endpoints without creating an account.

---

## Google Ads Best Practices Applied

Based on research from [WordStream](https://www.wordstream.com/blog/google-ads-copy), [Search Engine Land](https://searchengineland.com/google-ads-headlines-guide-455715), [Google Ads Help](https://support.google.com/google-ads/answer/6167122), and [Midsummer Agency](https://midsummer.agency/blog/best-practices-for-writing-google-ads-headlines-that-convert/):

### Character Limits (Responsive Search Ads)
- **Headlines**: Up to 30 characters each (max 15 headlines per RSA)
- **Descriptions**: Up to 90 characters each (max 4 descriptions per RSA)

### Key Principles Used
1. **Benefit-first language** — "Save hours" beats "AI technology"
2. **Urgency & scarcity** — "Today," "Now," triggers 16% higher CTR
3. **Specificity with numbers** — "Under 2 minutes" beats "Fast"
4. **Problem-solution framing** — Address pain points directly
5. **Strong CTAs** — "Try Free," "Get Started," "No Signup"
6. **Social proof indicators** — Trust-building phrases
7. **Unique value props** — Self-healing, no-code, AI-powered

## A/B Testing Recommendations

Based on [KlientBoost B2B SaaS research](https://www.klientboost.com/google/b2b-google-ads/):

1. **Test 3-5 RSAs per ad group** with different angles:
   - Problem-focused: "Scrapers Keep Breaking?"
   - Solution-focused: "Self-Healing Web Scrapers"
   - Benefit-focused: "Build Scrapers in 2 Min"

2. **Pin strategically** — Only pin Headline 1 and 2 when critical

3. **Rotate emotional triggers**:
   - FOMO: "Stop Losing Data"
   - Relief: "No More Maintenance"
   - Speed: "Ready in 2 Minutes"

4. **Test CTAs**:
   - "Try Free"
   - "Get Started"
   - "No Signup Required"
   - "Test Now"
