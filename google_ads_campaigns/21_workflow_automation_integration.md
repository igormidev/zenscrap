# Google Ads Campaign: Workflow Automation / Integration Platforms

**Campaign Theme:** Target users of visual workflow automation platforms (n8n, Make, Zapier, Power Automate) who need web scraping as part of their automation pipelines. These users search for scraper integrations, HTTP request solutions, and API endpoints that work seamlessly with their platform's HTTP Request nodes.

**Target Audience:** Technical and semi-technical users building visual workflows who need reliable web scraping without writing custom code. They value API endpoints, CURL commands, JSON responses, and easy HTTP integration.

## Key Insights from Research

### Why Workflow Users Need Better Scraping
1. **n8n HTTP node limitations:** Default user agent is axios, which triggers anti-bot protection
2. **JA3 fingerprint issues:** Node.js fingerprint triggers Cloudflare protection
3. **Dynamic content:** Native n8n scraper can't handle JavaScript-rendered sites
4. **403 errors:** Common pain point when scraping protected sites
5. **Rate limiting:** Users struggle with batching and delays

### ZenScrap's Competitive Advantages for This Audience
1. **Ready-to-use CURL:** Perfect for HTTP Request nodes
2. **Self-healing:** Eliminates maintenance burden
3. **Anti-bot handling:** Solves the 403 error problem
4. **JS rendering:** Handles dynamic sites automatically
5. **No code:** Describe what you want in plain English
6. **JSON response:** Standard format for workflow automation
