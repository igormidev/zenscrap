## Campaign Notes

### Target Audience
- Developers frustrated with anti-bot blocks
- Data engineers dealing with scraping failures
- Businesses needing reliable data extraction
- Teams without time to manage proxy infrastructure

### Negative Keywords (Exclude)
- free proxy list
- manual captcha solver
- captcha entry job
- captcha typing work
- bot creation
- hack website
- illegal scraping

### Bidding Strategy Recommendation
Start with Target CPA or Maximize Conversions. These keywords have high commercial intent from users actively seeking solutions to blocking problems.

### Landing Page Alignment
Ensure landing page prominently features:
- Anti-bot capabilities (CAPTCHA solving, IP rotation)
- List of systems bypassed (Cloudflare, DataDome, Akamai, etc.)
- "No setup required" messaging
- Free trial CTA with no signup barrier
